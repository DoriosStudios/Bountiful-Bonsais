# Bountiful Bonsais v1.1.0

This update reworks Bountiful Bonsais with improved visuals, more reliable growth, and native compatibility with Bountiful Crops and Bountiful Trees.

## HIGHLIGHTS
- Reworked the Bonsai system, models, textures, and growth animations.
- Added native compatibility with Bountiful Crops and Bountiful Trees.
- Added the Azalea Bonsai.
- Improved performance and reliability when using multiple Bonsais.

---

## GAMEPLAY
- Growth speed and output now scale correctly with the selected soil.
- Tilled Bonsais consistently apply their intended growth bonus.
- Bonsai animations remain synchronized with their actual growth time.
- Bonsais insert drops into compatible containers below without ejecting excess items.
- Decorative and existing Bonsais now pause, resume, and update more reliably.
